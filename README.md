# Taamim design language / שפת העיצוב של טעמים

Reference page for the Taamim app's design language: original SVG graphics, color palette and app screens, for rebuilding the same style (e.g. a landing page).

Live page: https://taamim-audio.github.io/design-language/

- `assets/svg/` - 99 original SVG graphics (clouds, level scrolls, taam boxes/balls/symbols, buttons, icons)
- `assets/screens/` - app screenshots (personal details removed)
- `index.html` - the reference page (Hebrew, RTL)
